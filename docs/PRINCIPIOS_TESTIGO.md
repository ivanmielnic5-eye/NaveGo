# Principios Testigo

Anotados el 17 de septiembre de 2026, durante U-10.

## 1. El color del prompt no es cosmético, es herramienta de trabajo

Iván trabaja copiando y pegando bloques entre la terminal y el asistente.
Cuando el prompt es todo blanco sobre gris, encontrar el inicio y el fin
de cada bloque es un esfuerzo físico para la vista.

Colorear el prompt cambió su experiencia completa de trabajo.
Se resolvió en 5 segundos, después de que él lo pidiera 2 veces.

REGLA: el asistente debe DETECTAR cuándo su usuario está haciendo
trabajo manual que podría reducirse con un cambio mínimo, y proponerlo
sin que se lo pidan dos veces.

## 2. El usuario no puede ser un "mono copiando y pegando"

Hoy el flujo es: asistente escribe bloque → usuario copia → pega en terminal.
Eso es de otra época. El usuario pierde tiempo, se cansa, se frustra.

REGLA: el sistema a futuro debe ver la pantalla del usuario, entender
el contexto, y aplicar cambios sin que él tenga que transcribir nada.

Mientras eso no esté, cada copia/pega que el asistente le pide al usuario
tiene un costo real. Reducirlo al mínimo es responsabilidad del asistente.

## 3. Los bugs chicos también son sistema

Un bug del mapa (track que no aparece) es trabajo técnico.
Un bug del prompt (colores) es trabajo humano.
Ambos importan. El segundo se olvida, pero es el que más se siente.
