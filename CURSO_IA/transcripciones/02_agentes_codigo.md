# Transcripción 02 — Agentes de Código

Fuente: Curso "Crear una aplicación con inteligencia artificial" (Anthony Souza / HOTMARK)
Fecha de subida: 2026-09-15
Tema: Agentes de IA para escribir código

## Notas clave

- Nadie escribe código a mano hoy en día.
- Se necesita un agente de código con IA.

### Agentes mencionados
- Cloud Code (Anthropic)
- Codex (OpenAI) — **preferido del autor**
- Cursor
- Open Code
- Pie

### Recomendación del autor
- Codex con suscripción ChatGPT Plus alcanza para mucho.
- Cursor ofrece buena relación precio/valor (tiene modelos de Grok y propios).
- El curso se hará en Codex (pero es transferible a los demás).

### Relevancia para NaveGo
- NaveGo usa agentes locales (Ollama + Harness) en lugar de servicios en la nube.
- Principio de soberanía: preferir agentes locales cuando sea posible.
- Aprendizaje: la elección del agente es de gusto, lo importante es el flujo de trabajo.
