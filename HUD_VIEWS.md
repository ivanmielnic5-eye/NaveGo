# HUD VIEWS — Información por Cámara

Fecha: 2026-08-25

## Cámara 1 — Lateral / Persecución

Enfoque: maniobra, escora, interacción con olas.

Datos visibles:
- SOG
- COG
- HDG
- AWS (velocidad del viento aparente)
- AWA (ángulo del viento aparente)

## Cámara 2 — Cenital / Estratégica

Enfoque: posición, derrota, entorno.

Datos visibles:
- Posición LAT/LON simulada
- COG
- Error de estima (diferencial)
- Zona activa del Landscape
- Estado del sistema

## Cámara 3 — Proa / Inmersiva

Enfoque: navegación a ras de agua.

Datos visibles:
- COG
- SOG
- AWA
- Rumbo deseado (cuando haya misiones)
- Controles de timón visibles
