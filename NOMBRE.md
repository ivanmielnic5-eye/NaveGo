# NOMBRE DEL SISTEMA UNIVERSAL

## Decision
El sistema universal de orquestacion humano-IA se llama LOGOS.

## Etimologia
logos (griego) = palabra, razon, discurso, verbo.
Proviene de legein: recoger, ordenar, decir, relatar.

## Justificacion
Logos representa recoger, ordenar y ejecutar la intencion humana.
No es un dashboard: es una capa de razon y verbo.

## Relacion con Cockpit
- Cockpit es la superficie visual.
- Logos es el alma conceptual del sistema.

## Estado
Decision congelada como referencia arquitectonica.
