# COCKPIT CORE SPEC — Sistema Universal Humano-IA

Actualizado: 2026-08-19

## Proposito
Definir el nucleo conceptual y arquitectonico de una interfaz universal de coordinacion
entre un humano Director y una IA Directora Tecnica.

## Reglas congeladas
1. Los cinco modulos son universales: ESTADO, TRABAJO, EVIDENCIA, ARCHIVOS, ACCION.
2. Salud es un contenedor dinamico, no un conjunto fijo de sensores.
3. Los proyectos se conectan mediante adaptadores.
4. Estado global y contexto de proyecto estan separados.
5. NO VERIFICADO es un estado legitimo, no un error.
6. La intencion humana atraviesa todo el sistema sin convertirse necesariamente en otro modulo.
7. Ningun proyecto puede introducir una categoria visual al Core sin demostrar que esa categoria existe en mas de un dominio.

## Capas
CORE: Estado, Trabajo, Evidencia, Archivos, Accion.
SYSTEM: Salud, Eventos, Riesgo, Integraciones.
PROJECT ADAPTERS: NaveGo, GAIA, futuros proyectos.

## Ciclo cognitivo
ESTADO responde a: Que esta pasando?
TRABAJO responde a: Que estamos intentando hacer?
EVIDENCIA responde a: Que demuestra el resultado?
ARCHIVOS responde a: Donde vive el conocimiento persistente?
ACCION responde a: Que puede hacer el humano o la IA?

## Jerarquia
Nivel 1: Ahora, lo que requiere atencion.
Nivel 2: Contexto, lo que esta ocurriendo.
Nivel 3: Profundidad, evidencia, archivos y detalles.

## Salud del sistema
La gramatica visual es fija: una fila de indicadores compactos.
El contenido es dinamico: cada proyecto define sus propios indicadores.
Ejemplo NaveGo: GNSS, SYNC, SERVER, TRACKING, PERSIST.
Ejemplo GAIA: CAMERA, DATA, PIPELINE, ANALYSIS, STORAGE.

## NO VERIFICADO
Se representa visualmente distinto de error.
Puede ser gris punteado o similar.

## Intencion
No es un sexto modulo. Atraviesa los cinco modulos.
La voz sera una forma de expresar intencion estructurada.

## Regla de silencio
Cuando todo esta bien, la pantalla puede estar casi vacia.
Cuando aparece algo importante, el instrumento despierta.

## Metáfora visual
Instrumento de orquestacion, no dashboard.
Observa, interpreta, permite intervenir, registra, vuelve a observar.

## Principio fundamental
La IA maneja la complejidad. El humano conserva el control de la intencion.
Evidencia antes que certeza.
